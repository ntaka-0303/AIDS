# 要件の統合版（ヒアリング都度更新）

## Phase 1: PoC対象要件

### REQ-001: ナレッジ統合・情報検索機能【最重要】
- **種別**: 機能要件
- **優先度**: High
- **概要**: 複数システムに分散した情報を横断検索し、要点を抽出する
- **背景**:
  - 現状: 市況、商品、規程、過去提案、FAQなど10以上のシステムを横断して検索
  - 頻度: 週10〜15件/人（繁忙期は1.5〜2倍）、発生タイミングは顧客訪問前日・当日朝・提案書作成途中
  - 課題: 1案件あたり30〜60分の検索時間を要する（現在平均40分）
  - 課題: 過去提案が支店ローカルに保存され埋もれている
  - 課題: 情報がサイロ化していて横断検索できない、最新資料の所在が不明確、PDFやPPTが多く手作業で読み込むしかない
  - ペインポイント: 時間負荷・心理負荷が最も大きい領域。類似提案が見つからない、情報量が多く精読できない、古い資料と新しい資料が混在
- **期待効果**: 統合検索＋要点抽出による検索時間の大幅削減
- **KPI（DEC-012）**: 情報検索時間を40分→20分に短縮
- **Phase1対象データ（DEC-007, DEC-015）**:
  - 調査部レポート: PDF形式、月次発行、直近1年分約50レポート、1レポート20-50ページ
  - 商品資料: PowerPoint/PDF形式、主力30商品、1商品あたり10-30スライド
  - FAQ: Excel→CSV形式、約200件、カテゴリ別分類（商品、規程、システム操作、顧客対応等）
  - ※過去提案書は支店分散のためPhase1では対象外
- **データアクセス方法（DEC-018）**: 社内ポータル/商品企画部から取得→AI Workspaceセキュア領域にアップロード
- **出典**: 初回ヒアリング内容.md, PoC候補整理結果へのコメント.md, 2026-01-22_計画フェーズ詳細確認.md, 情報検索_市況整理のヒアリング結果.md

### REQ-002: 市況整理・要約機能
- **種別**: 機能要件
- **優先度**: High
- **概要**: 市況レポートを営業向けに要約し、顧客への説明に活用できる形に整理
- **背景**:
  - 現状: 市況レポートが多すぎて若手が要点を掴めない
  - 頻度: 重要提案前に深掘り週3〜5件、簡易チェックは毎朝実施
  - 所要時間: 20〜40分/件
  - 課題: 市況情報から顧客向け説明への落とし込みが困難
  - 若手の苦手ポイント: 重要情報の取捨選択、市況⇄商品を結びつけること、専門用語の理解、市況ストーリーの構築
  - ペインポイント: レポートの情報量が多すぎて読む時間がない、若手は専門用語を理解できず顧客向けの説明に落とし込めない、営業スキルの属人性が最も顕著な領域
  - 調査部の懸念: 表現のぶれ、過度に断定的な内容、特定銘柄推奨に見える記述、公式見解との齟齬
- **期待効果**: 若手支援、市況理解の底上げ
- **KPI（DEC-012）**: 市況理解度を5段階評価で平均4.0以上に向上
- **データ仕様（DEC-013）**:
  - 提供範囲: 直近3ヶ月分（約12レポート）
  - フォーマット: PDF（テキスト抽出可能）、1レポート10-20ページ
  - 更新頻度: 週次（毎週金曜日発行）
  - 標準セクション構成: エグゼクティブサマリ、市場動向分析、セクター別詳細、今後の見通し、営業への示唆
- **レビュー体制（DEC-008, DEC-017）**:
  - レビュー担当: 調査部 田中課長（週次5-10件対応可能）
  - レビューフロー: AI生成→1次レビュー（営業担当）→2次レビュー（調査部）→承認・公開
  - レビュー観点: 要約の正確性、営業向け表現の適切性、機密情報除外、コンプライアンス
  - レビュー期限: 生成から48時間以内
- **出典**: 初回ヒアリング内容.md, PoC候補整理結果へのコメント.md, 2026-01-22_計画フェーズ詳細確認.md, 情報検索_市況整理のヒアリング結果.md

### REQ-003: 提案資料作成支援機能
- **種別**: 機能要件
- **優先度**: Medium
- **概要**: 提案書のたたき台を自動生成し、作成時間を短縮
- **背景**:
  - 現状: 毎回スクラッチで作成、最新情報の反映漏れが発生
  - 課題: 1〜2時間/提案の作成時間（現在平均1時間）
- **期待効果**: 資料作成時間の短縮、品質の底上げ
- **KPI（DEC-012）**: 提案書作成時間を1時間→30分に短縮、品質スコア（レビュー指摘件数）を20%削減
- **Phase1対象テンプレート（DEC-016）**:
  - **商品提案テンプレート（最優先）**:
    - スライド構成: 表紙、背景、商品概要、メリット、リスク、次のステップ（計10-15スライド）
    - AI適用範囲: 背景、商品概要、メリット、リスクのテキスト生成
    - 入力情報: 顧客名、商品名、市況情報、顧客課題
  - **ソリューション提案テンプレート**:
    - スライド構成: 表紙、課題整理、ソリューション概要、効果試算、導入ステップ（計15-20スライド）
    - AI適用範囲: 課題整理、ソリューション概要のテキスト生成
    - 入力情報: 顧客名、課題、提案ソリューション、市況情報
  - ※コンサルティング提案はPhase2以降
- **PoC実施方針（DEC-009）**:
  - Phase1では既存レイアウトのみ対応
  - テンプレートがない領域はテキスト生成のみ
  - レイアウト変更や新テンプレート作成はPhase2以降
- **テンプレート提供**: PowerPointファイル（サンプル付き）を1/24までに山口マネージャーから共有
- **出典**: 初回ヒアリング内容.md, PoC候補整理結果へのコメント.md, 2026-01-22_計画フェーズ詳細確認.md, 情報検索_市況整理のヒアリング結果.md

## 非機能要件

### REQ-007: セキュリティ・データ連携
- **種別**: 非機能要件
- **優先度**: High
- **概要**: データ連携時のセキュリティ制約への対応
- **状態**: 方針合意済み（QST-004, QST-006, QST-007, QST-009解決）
- **確定方針（DEC-011, DEC-018, DEC-023）**:
  - データアップロードはAI Workforceのセキュア領域に限定
  - ファイル形式混在はAI側で吸収可能
  - 個人情報はPoCで扱わない（監査リスク回避）
  - Phase1は外部システム連携なし（ファイルアップロードのみ）
- **技術仕様（DEC-018）**:
  - **アップロード方法**: Webインターフェース経由（ドラッグ&ドロップ）
  - **対応フォーマット**: PDF, PowerPoint, Excel, Word, CSV
  - **ファイルサイズ制限**: 1ファイル50MBまで
  - **セキュリティ機能**: TLS暗号化、アクセスログ記録、ウイルススキャン自動実行
  - **データ保持期間**: PoC期間中のみ（PoC終了後は全削除）
- **データ更新フロー（DEC-018）**:
  - **初期アップロード**: 2/1-2/7に全データソースをアップロード
  - **定期更新**: 市況レポート（週次）、調査部レポート（発行の都度）、商品資料（更新の都度）、FAQ（月次）
  - **更新担当**: DX推進部 担当者（杉本部長の部下）
- **可用性・運用保守（DEC-019, DEC-020）**:
  - **稼働時間帯**: 24時間365日稼働（PoC参加メンバーの主利用時間は平日9:00-18:00）
  - **定期メンテナンス**: 毎週日曜3:00-5:00、緊急メンテナンスは24時間前通知
  - **サポート時間**: LayerX平日9:00-18:00対応
  - **サポート体制**: Slack第1窓口（#abc-corp-poc-support）、緊急時は技術リード直通電話
  - **対応SLA**: 重大障害1時間以内、中程度障害4時間以内、軽微1営業日以内
  - **エスカレーションフロー**: Slack→電話→技術リード→PM→CTO（重大時のみ）
- **インターフェース要件（DEC-021）**:
  - **対応ブラウザ**: Chrome/Edge 110以降、Safari 16以降（Firefox対応予定なし）
  - **対応デバイス**: PC完全対応（推奨解像度1920x1080以上、最小1366x768）、タブレット基本機能のみ（PoCでは検証対象外）、スマホ非対応
  - **PoC環境**: Chrome/Edge最新版 + Windows PC（プロキシ設定済み、ウイルスバスター導入済み）
- **受入条件（DEC-022）**:
  - **必須項目**: (1)KPI達成、(2)システム安定性（重大障害0回、中程度月2回以下、データ損失0件）、(3)データ品質（検索精度80%以上、要約精度平均4.0以上、誤情報5%以下）、(4)ユーザビリティ（アンケート平均3.5以上、業務に役立つ80%以上、重大操作性問題0件）、(5)セキュリティ・コンプライアンス（個人情報漏洩0件、不正アクセス0件、ポリシー違反0件）
  - **Phase2移行判断**: 経営会議で決定、特に誤情報生成は経営層の懸念事項で厳格評価
- **出典**: 初回ヒアリング内容.md, PoC候補整理結果へのコメント.md, 2026-01-22_計画フェーズ詳細確認.md, 情報検索_市況整理のヒアリング結果.md, 2026-01-15_技術要件とPoC受入条件の詳細確認.md
