# 要件の統合版（ヒアリング都度更新）

## 要件一覧

### REQ-001: 顧客ヒアリング支援機能
- **タイプ**: functional
- **優先度**: Medium
- **説明**: AIによるヒアリングガイド機能、およびCRMメモからの提案方向性を抽出する機能
- **背景**: CRMメモの記載が属人化しており、若手は聞き漏れが多い。過去メモから提案方向性を把握するのが困難
- **出典**: 2026-01-12 初回ヒアリング

### REQ-002: 統合情報検索機能
- **タイプ**: functional
- **優先度**: High（最重要）
- **説明**: 市況、商品、規程、過去提案、FAQなど複数システムを横断する統合検索機能
- **背景**: 現状は10以上のシステムを横断検索しており、1案件で30〜60分の検索時間を要している
- **出典**: 2026-01-12 初回ヒアリング
