# プロジェクト憲章

## プロジェクト名
AI Workforce PoCプロジェクト（リテール営業部門）

## 目的
リテール営業部門の業務課題を把握し、AI Workforceの適用領域を検討・実証する。
提案業務の品質向上と生産性向上を主目的とする。

## スコープ
リテール営業部門の提案業務全体を対象とし、PoCでは優先度の高い領域に絞って段階的に導入を進める。

### PoC対象領域（Phase 1）
1. **情報検索（ナレッジ統合・要点抽出）** - 最重要
2. **市況整理（要約・示唆出し）**
3. **提案資料作成（たたき台生成）** - 必要に応じて含む

### 2nd Phase候補
- 顧客ヒアリング支援（ヒアリングガイド、CRMメモ分析）
- 商品選定サジェスト
- 上長レビュー支援

## 対象業務プロセス
1. 顧客ヒアリング
2. 情報検索
3. 市況整理
4. 商品選定
5. 資料作成
6. 上長レビュー

※ 実際には②〜④の間で行き来が発生し、手戻りが多い
